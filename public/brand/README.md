# Logotipo oficial

Espacio reservado para el logotipo oficial de VicMan QR.

Para reemplazar el monograma provisional:

1. Copia aquí el archivo del logotipo (preferiblemente `logo.svg`).
2. En `src/components/layout/BrandMark.tsx`, cambia `LOGO_SRC` de `null` a `'/brand/logo.svg'`.
3. Opcional: reemplaza también `public/favicon.svg`.
